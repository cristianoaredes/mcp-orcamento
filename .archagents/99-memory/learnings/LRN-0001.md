# LRN-0001 — Varredura pos-publicacao de notas pre-release em README e MCP_CLIENT_INTEGRATION

## Context

**Ticket:** TCK-0003
**PRR:** PRR-0004
**Category:** improvement
**Severity:** low

## Signal That Originated This Learning

Na auditoria pós-publicação do `PR #1` (`TCK-0003`) após o publish de `@aredes.me/mcp-orcamento@0.1.0`, detectaram-se ocorrências remanescentes de `"Não possui pacote publicado no npm"` (`README.md:301`), `# Após publicação no npm:` (`README.md:195`) e paths locais `node build/lib/bin/mcp-orcamento.js` nas seções de clientes em `docs/MCP_CLIENT_INTEGRATION.md`, exigindo o commit complementar `e226cb1`.

## Cause / Pattern

Guias redigidos antes da primeira publicação `v0.1.0` distribuem avisos de pré-lançamento e comandos locais por múltiplas seções e arquivos; atualizações manuais parciais deixam seções secundárias desatualizadas.

## Impact

Usuários copiando configurações de clientes MCP (Cursor, Claude Code, Windsurf, Cline, Continue) encontrariam instruções locais em vez de `npx -y @aredes.me/mcp-orcamento`.

## Recommendation

Executar grep de frases de pre-publicacao e paths locais em todos os guias apos primeiro publish 0.1.0 no npm
